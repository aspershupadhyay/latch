# Getting help

| You want to… | Go here |
|---|---|
| Set Latch up | [Setup guide](docs/setup.md) |
| Fix "App blocked", "Restricted setting", dropped sessions, or slow actions | [Troubleshooting](docs/troubleshooting.md) |
| Know what the AI can and cannot do | [Safety and privacy](docs/safety.md) |
| Report a bug | [Open a bug report](https://github.com/aspershupadhyay/latch/issues/new/choose) with your phone model, Android version, and gateway type |
| Suggest a feature | [Open a feature request](https://github.com/aspershupadhyay/latch/issues/new/choose) |
| Report a security problem | [Privately, never in an issue](https://github.com/aspershupadhyay/latch/security/advisories/new) |

Before posting, ask your AI app to run the `diagnose` tool: it checks the pairing, session, app version, and switches, and names the fix. Never paste owner keys, AI app keys, screenshots of private apps, or Activity logs with personal data into an issue.
